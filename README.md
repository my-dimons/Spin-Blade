<img src="Release Art/Cover v3.png" align="right" width="300" />

### Play here: https://mydimons.itch.io/spin-blade

Spinblade is a game made in (originally) 4 days for the [2025 GMTK game jam](https://itch.io/jam/gmtk-2025). 
People seemed to like the game so I continued to make updates. 
I released [v2.0](https://mydimons.itch.io/spin-blade/devlog/1004497/v20-revamping-spinblade) a few months later which brought tons of improvements and content. 
Then 5 months later I released [v3.0](https://mydimons.itch.io/spin-blade/devlog/1107673/v30-mobile-mayhem), which brought mobile compatability. 

I also tried making [videos](https://www.youtube.com/playlist?list=PLjrzpl_K_WMzFipiYixRg4m0jjO4Us8Eb) on Spinblade to bring some attention to it, which worked because your reading this right now!

Hope you enjoy playing!
